# 序言

我是一名互联网行业的研发工程师。我从小就喜欢数学，喜欢钻研逻辑性强的东西。年少时也参加过数学竞赛培训，虽然没有取得过很好的成绩。后来的工作经历却让我越来越深刻地意识到：我虽然接受了十几年的数学教育，却并没有真正理解数学。 如今一晃几十年过去了，我的孩子也开始牙牙学语，到了进行数学启蒙的时候。我深知数学的重要性，也深知传统数学教育存在的一些问题，却很难找到一本真正符合我心目中学习方式的数学书，能够用来给我的孩子讲授数学。于是，我决定自己写一本这样的书。我希望我的孩子能够避开我们当年学习数学时踩过的那些坑，不必把大量时间花在死记硬背上，而是从最基础的地方出发，一步一步用推理的方式去理解数学。我希望她能够用很少的精力，掌握强大的数学工具。更重要的是，真正看懂数学是怎样一步一步建立起来的，最终能够自己继续向前探索，领略到数学世界真正的美。

在我几十年的工作生涯中，每当回想自己年少时学习数学的经历，都会感到深深的遗憾。我明明已经具备了学习近世代数的能力，却没有在学生时代真正去接触和掌握这些知识。等到后来我在工作中需要涉及 AI、空间智能、自主导航、轨迹预测等领域时，反而不得不重新补习数学。也正是在工作中重新自学数学，以及同步学习其他相关学科知识的过程中，我越来越清楚地感受到，传统数学教育存在着一些根本性的问题。它并不是完全错误的，相反，其中有大量行之有效的方法，只是它往往更加关注“如何让学生快速得到正确答案”，而没有足够关注“学生是否真正理解了答案以及为什么是这个答案”。当一个成年人重新回头学习数学时，这种差异会变得尤其明显：曾经背得滚瓜烂熟的公式，可能很快忘记；曾经做过成百上千遍的题型，也可能多年不用就无从下手。但如果真正理解了一个公式为什么成立，理解了一个定理是怎样从更基本的事实中推导出来的，那么即使多年以后忘记了公式本身，也完全可以重新把它推导出来。

首先，传统数学教育过于奖励死记硬背和套路。绝大多数数学考试，甚至包括数学竞赛，都非常强调对题型的识别速度和解题熟练度。拿到一道题，你需要在很短的时间内判断：这是哪个题型？应该使用哪个公式？应该套用哪个定理？这种能力当然有它的价值，数学家、工程师以及任何从事技术工作的人，都需要熟练掌握工具。但问题在于，当这种能力成为数学学习最主要的目标时，数学就很容易变成一种“模式匹配 + 熟练度”的竞技体育。很多学过数学的人，能够熟练使用勾股定理，却并不真正知道勾股定理为什么成立；能够熟练使用各种函数公式，却未必想过这些公式究竟是如何产生的。不信的话，可以问问自己：勾股定理是怎么证明的？圆的面积为什么是 $\pi r^2$ ？为什么 $y=\frac{1}{x}$ 的图像是双曲线？ 如果只是记住结论，却不知道结论为什么成立，那么我们究竟是在学习数学，还是在学习如何记住数学题的答案？

这种“模式匹配 + 熟练度”的学习方式，会进一步带来一系列问题。首先是不求甚解，只求得分。明明不理解，却不愿意继续研究；明明不知道为什么，却只需要记住公式，然后通过大量刷题训练出条件反射，只要最后能够得到正确答案，就算完成了学习。这种浅尝辄止的态度，会导致对数学这门学科的认识始终比较肤浅。在数学上花了大量的时间，但收效甚微。其次是越学越累。理工科不只有数学，还有物理、化学；到了大学，如果选择工科，还会遇到编译原理、数字信号处理、数据结构与算法等大量工科课程。如果每一门理工课程都依赖记忆，那么知识越学越多，记忆量也会越来越大，最终大脑不堪重负，甚至逐渐失去对数学的兴趣。但真正的问题也许并不是数学太难，而是我们没有掌握足够好的学习方式。如果一个人理解了知识背后的结构，那么大量看似不同的公式和结论，往往可以被统一到少数几个更基本的原则之下。知识不再是一大堆需要背诵的孤立信息，而会变成一个相互连接的系统。系统一旦建立起来，学习反而会越来越轻松，而不是越来越沉重。

第三，是学校奖励熟练度，却不一定奖励真正的数学思维。考试天然适合评价那些可以快速、稳定地给出答案的能力，因此大量刷题、熟悉套路的学生，往往更容易取得好成绩。但真正的数学思维——发现问题、提出猜想、寻找规律、建立模型、进行证明、推广结论——却很难通过一张试卷被完整地评价。这意味着，一些真正具有创造力的人，反而可能被这样的评价体系错过。第四，是很多数学书一上来就过于抽象。翻开一本数学书，很快就会遇到严密的定义、复杂的符号和抽象的证明。这种方式对于已经具备相应数学基础的人非常高效，但对于初学者却可能非常困难。人类学习和理解新知识，往往是从具体到抽象、从特殊到一般。如果一开始就把最终抽象出来的语言直接交给孩子，却不告诉他这些概念究竟是怎么产生的，那么数学很容易变成一堆令人望而生畏的符号。有些人凭着兴趣和毅力，勉强啃下十几页；但最终因为实在看不懂，开始怀疑自己是不是不够聪明。

这就导致很多普通人形成了一个对数学根深蒂固的误区：智力自卑。 他们以为数学就是做难题，以为数学题越难，就越能证明一个人的聪明程度；学不好数学，就怀疑自己是不是智商不够。然而，我在重新学习数学的过程中越来越强烈地感受到，事实恰恰没有那么悲观。数学中那些看起来恐怖的符号背后，往往隐藏着极其简单的思想。数学家为了准确、高效、简洁地表达思想，把大量内容压缩成了非常简洁的定义、符号、公式和定理。对于已经熟悉这种语言的人来说，这种表达非常优雅；但对于初学者来说，它就像文言文一样，几个字背后可能隐藏着大量没有说出来的信息。真正的问题并不是孩子没有能力理解数学，而是我们常常直接把“压缩后的最终形式”交给孩子，却没有带着孩子经历知识从具体问题逐渐走向抽象概念的过程。

我相信，数学中大量看似高深的知识，都可以用一种知识上诚实的方式，教给不同年龄的学习者。这里所谓“知识上诚实”，并不是把高等数学强行变成几句儿童故事，也不是故意隐藏那些真正困难的部分，而是尊重知识本身的来龙去脉：需要解决一个问题，分析思考问题的本质，通过小的数据和少量案例验证，发现其中的规律，最终把规律推广到更一般的形式，并通过证明确认它为什么成立。只是把每一个抽象概念拆成足够多的台阶，让学习者能够一步一步走上去。孩子当然不可能一开始就理解完整的近世代数，但这并不意味着他不能从很小的时候开始接触“结构”、“映射”、“不变量”、“证明”这些思想。就像孩子可以先理解“两个东西放在一起是多少”，再逐渐理解加法；可以先观察具体的小球排列，再逐渐理解乘法；最终，他完全可以沿着同一条知识链条，走向越来越抽象的数学。真正重要的不是孩子现在能学多难，而是我们有没有把通往更高处的台阶搭好。

那么，数学究竟是什么？在我看来，数学至少有两个非常重要的特点。第一，数学是一种从少数基本事实出发，建立庞大理论体系的方法。数学家会从一些基本的定义、公理或者显而易见的事实出发，然后一步一步推导出新的结论。看起来庞大的数学体系，并不是凭空出现的，也不是由无数互不相关的公式堆砌而成的，而是可以从少量基础出发，一层一层建立起来。欧几里得几何就是一个经典的例子。我们今天看到的欧氏几何包含大量定理、公式和复杂的证明，但这些知识并不是彼此孤立的，而是可以从少数基本概念和公理出发，一步一步推导出来。这种思想推广到其他领域，就是我们今天经常说的第一性原理：不要只记住别人告诉你的结论，而是回到最基本的事实，重新思考问题是如何产生的，结论又是如何从这些基本事实中一步一步推导出来的。这也是我希望这本书带给孩子的第一种能力。

数学的第二个重要特点，是它非常擅长研究“不变的东西”和“背后的结构”。一个三角形无论怎样改变形状，它的三个内角之和始终是 \(180^\circ\)；一个圆无论大小如何变化，周长与直径的比始终相同，这个数就是 \(\pi\)。数学家不断寻找这种变化之中的不变性，并试图用精确的语言描述它们。物理学中的“不变性”则更加深刻。诺特定理告诉我们，在满足一定条件的物理系统中，连续对称性与守恒定律之间存在对应关系，例如时间平移对称性对应能量守恒。但数学还有另一种非常迷人的能力：从表面完全不同的事物中，发现它们背后相同的结构。在数学中，我们把这种保持结构的对应关系称为“同构”。例如，在工程物理中，一个由弹簧、滑块和阻尼器组成的机械振动系统，与一个由电感、电容和电阻组成的电路系统，它们虽然属于完全不同的物理系统，却可以用形式相同的数学模型来描述。一个研究机械系统的人和一个研究电路系统的人，甚至可以借用完全相同的数学工具。表面上，一个是机械系统，一个是电路系统；但在数学层面，它们却拥有相同的结构。这就是数学最迷人的地方之一：它研究的不只是对象本身，更是对象之间的结构、关系和规律。

在我看来，真正学好数学，并不需要超高的智商，而需要的是专注、仔细，以及一种正确的学习方式。孩子不应该花大量的时间去刷题，而是应该花时间理解人们在现实世界里遇到了什么问题，数学家是怎么思考这个问题的，又是如何去尝试解决和验证的，最终问题是怎么一步一步上升为一般规律、公式和定理的。习题的设计，不是为了难倒孩子，而是应该把抽象的过程具体化，让孩子用实践的方式去深刻理解抽象的概念和过程。最后，孩子需要用自己的方式，把所有的公式、定理、推论自己推导出来。这样一来，孩子就会有一个牢固的数学基础，所有的结论就像是自己发明的一样。甚至，在未来孩子遇到未知的问题时，自己就能从少数几条观察到的现象出发，一步一步建立自己的理解，甚至形成自己的理论体系。

因此，这本书真正希望带给孩子的，并不是更多的公式，而是几种更底层的能力。第一，是用第一性原理理解数学：从少量的基本事实出发，一步一步推出新的结论，真正知道每一个结论为什么成立。忘记公式和定理没有关系，只要你知道公式和定理是怎么来的。我希望教给孩子的，不是几条猎枪，而是制造猎枪的图纸。第二，是从具体到抽象、从特殊到一般：先观察一个具体的问题，再发现其中的规律；先理解一个简单的例子，再逐渐推广到一般情况；先让孩子看见一个数学对象，再慢慢告诉她我们为什么需要给这个对象起一个名字，为什么需要一个符号，为什么最终要把它抽象成一个定义。第三，是破除智力自卑。我希望孩子知道，数学不是只有聪明人才能学习的东西，很多看似高深的数学知识，都可以从最基础的地方一步一步建立起来。只要给出足够的台阶，孩子完全可以一步一步走上去。这里的目标并不是让孩子提前背会多少大学数学，而是让她从小形成一种信念：遇到不会的东西并不可怕，只要继续往下追问“为什么”，就总能找到更基础的地方。

第四，我希望这本书能够让孩子在传统教育中胜出。我们要超越传统教育，但并不抵触传统教育。传统考试当然有它存在的价值，计算能力、熟练度、准确性同样是数学能力的一部分；我们真正反对的，并不是考试，而是把考试中的得分技巧误认为数学本身。相反，我认为真正的超越应该经得起现实的检验。如果孩子真正理解了数学，而不是依靠死记硬背，那么她不仅应该能够理解数学，还应该能够在传统考试中取得好成绩；如果理解能够让学习变得更加高效，那么孩子就应该能够用更少的时间掌握更多的知识，并且在面对陌生问题时拥有更强的迁移能力。最好的证明，不是告诉别人我们的学习方法更好，而是让孩子用更少的时间，获得更好的学习效果。如果一个孩子既理解数学的底层逻辑，又能够在学校的考试中取得优秀成绩，那么这才是我认为真正意义上的“超越”。

最后，数学不仅是一门独立的学科，也是一种描述和研究其他科学的通用语言。它与物理、计算机科学、工程学等许多学科都有着深刻的联系。因此，我们希望孩子能够把学习数学的方法迁移到其他理工科的学习中，达到事半功倍的效果，并让这种从第一性原理出发的学习方式，在未来的学习和工作中长期受益。

所以，这本书不是一本“数学口诀大全”，也不是一本“解题套路大全”。我更希望它是一张方法论地图：让孩子知道数学从哪里开始，知道每一个概念为什么会出现，知道每一个公式为什么成立，知道每一个定理是怎样被发现、推导和证明出来的；更重要的是，在走完别人已经铺好的道路之后，她最终能够自己继续往前走。**因为真正重要的，并不是记住别人已经发现的答案，而是获得重新发现答案的能力**。当她忘记一个公式时，知道怎样重新把它推导出来；当她遇到一个陌生的领域时，知道怎样寻找其中最基本的事实、最稳定的规律和最深层的结构。如果这本书最终能够让一个孩子形成这样的思维习惯，那么我认为，它就已经完成了最重要的使命。

**愿天下没有难学的数学。**

**愿每一个孩子，都能感受到数学的美。**
