# 负数计算法

## 1. 自然数悖论

我们来看下面的算式：

$$2+3-5$$

现在我们几乎能瞬间得出答案：$0$。

还记得**广义交换律**吗？我们可以把“减$5$“与“加$3$”交换位置，而结果不变。也就是说：

$$2+3-5=2-5+3=0$$

那么问题来了。

自然数里不允许做$2-5$，于是$2-5+3$无意义。但是在自然数范围内，$2-5+3$却又等于$0$。

那么到底该怎么办？

## 2. 负数的定义

数学家观察到了这种现象。数学家发现，任意两个自然数做减法运算，有可能出现自然数无法描述的结果。这种现象，数学家称之为**不闭合**。

面对这种情况，数学家会做一件事情：**对自然数进行扩展**。换句话说就是，自然数不够用了。我们要创造一个新的“数”，把自然数扩一扩。

但是，扩展是有条件的，不能凭空捏造。数学上的扩展，必须满足**逻辑自洽**。所谓逻辑自洽，就是，让原有的自然数的公式，在新扩展的数上继续生效。这样，我们无论怎么扩展，只需要用一套公式即可。否则，扩展一次，公式数量翻倍，再扩展一次，公式数量再翻倍，没人愿意面对这么多相似而又不同的公式。

基于这个原则，数学家扩展出来的数，必须能够让 $2-5+3$ 等于零。数学家发现，$2$ 其实比 $5$ 少 $3$，这个“少 $3$”，加上后面的 $3$，正好等于零。

数学上规定，每一个自然数 $n$，都有一个**相反数**，记为 $-n$，它们俩加起来等于零：

$$\forall n \in \mathbb{N}, \quad n + (-n) = 0$$

我们把这个 $-n$ 叫做**负数**。全体**负数**加上全体**自然数**（以及 $0$），在数学上称为**整数**。

负数也有相反数。负数的相反数就是对应的正数。无论如何，一个数与它的相反数相加，结果为零。于是：

$$\forall n \in \mathbb{Z}, \quad n + (-n) = 0$$

这里的$\mathbb{Z}$，指的是全体**整数**。

所以，$1$ 的相反数是 $-1$，$15$ 的相反数是 $-15$，$-1$的相反数是$1$。特别的，$0$ 的相反数还是它自己，$0$ 既不是正数也不是负数，它是正负数交汇的“原点”。无论怎样，**一个整数与自己的相反数相加等于零**。

在这个定义下，所有基于自然数的公式对于整数全部有效。

## 3. 负数在应用中的意义

负数在生活中经常会出现。其中负数最常用来描述的，就是“亏损”。在中国古代，账本里会用红笔写下亏损额，黑笔写下盈利。红笔的“亏损额”就相当于“负数”。这也是中文里“赤字”(红色的字，表示亏损)的由来。

## 4. 负数的加减

我们观察下面两个等式（等式中的$a$为整数）：

$$
a-a=0\\
a+(-a)=0
$$

我们可以得出一个结论：**减去一个数，等价于加上这个数的相反数**。

所以下面的式子等价：

$$
5+(-1)=5-1\\
8+(-3)=8-3\\
(-5)+6=6+(-5)=6-5
$$

若是不够减怎么办？$2-5$等于多少？让我们观察一下这个等式$2-2+5-5$，是不是可以瞬间得出这个等式的值为$0$？让我们把这个等式变形，看看能得到什么。

$$0=2-2+5-5=2-5+5-2=(2-5)+(5-2)$$

看吧，根据**相反数**的定义，$(2-5)$的相反数是$(5-2)$。所以$(2-5)=-(5-2)=-3$。

一般的，我们有：

$$a-a+b-b=0 \implies (a-b)+(b-a)=0$$

因此，$a-b$与$b-a$是一对**相反数**。

那么，$-2+(-3)$呢？我们仍然可以运用相反数的定义：

$$0=-2+2+(-3)+3=-2+(-3)+2+3=(-2+(-3))+(2+3)$$

看吧，$-2+(-3)$的相反数是$2+3$，那么$-2+(-3)$等于$-5$。

假如我们有两个整数$a$和$b$，那么：

$$0=a+(-a)+b+(-b)=((-a)+(-b))+(a+b)$$

因此，$-a+(-b)$的相反数是$a+b$。

最后，我们看一下$3-(-2)$。

我们上面说过：**减去一个数，等价于加上这个数的相反数**。所以，当我们减去一个负数的时候，加上它的相反数（是一个正数）即可。因此：

$3-(-2)=3+2=5$

## 5. 负数的乘除

我们先来看一个负数乘以一个正数：

根据乘法的定义，乘法（乘数为正）就是连加。所以：

$$(-2)\times3=(-2)+(-2)+(-2)$$

考虑$-2$的相反数$2$，得：

$$2\times3=2+2+3$$

当我们把这两个式子加起来的时候，奇迹发生了。

$$(-2)\times3+2\times3=(-2)+(-2)+(-2)+2+2+2=(-2)+2+(-2)+2+(-2)+2=0$$

所以，$(-2)\times3$与$2\times3$互为相反数。那么$(-2)\times3$就等于$-6$。

一般的，有两个自然数$a$和$b$，那么：

$$(-a)b+ab=\underbrace{(-a)+(-a)+\cdots+(-a)}_{b}+\underbrace{a+a+\cdots+a}_{b}=\underbrace{((-a)+a)+((-a)+a)+\cdots+((-a)+a)}_{b}=0$$

所以，$(-a)b$与$ab$是一对**相反数**。根据定义，$ab$的相反数是$-ab$。最终得：$(-a)b=-ab$。

我们计算正数与负数相乘，就容易了。

$$
\begin{align}
&(-3)\times4 = -3\times4 = -12\\
&2\times(-7)=(-7)\times2=-7\times2=-14
\end{align}
$$

下面我们研究两个负数相乘。

让我们计算$(-2)\times(-3)$。

我们知道，$(-3)+3=0$。

我们把上式两边都乘以$-2$。得：

$$(-2)((-3)+3)=(-2)\times0=0$$

我们用**乘法分配律**做展开。

$$0=(-2)((-3)+3)=(-2)\times(-3) + (-2)\times3$$

所以，$(-2)\times(-3)$是$(-2)\times3$的相反数。$(-2)\times3$等于$-6$，它的相反数是$6$。所以，$(-2)\times(-3)=6$
